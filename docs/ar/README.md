استخدم هذا الفهرس للتنقل بين وثائق المشروع العربية. يمكنك الانتقال إلى الوثائق الإنجليزية الكاملة من زر اللغة أعلاه.

## الأدلة الأساسية

| الوثيقة | الغرض |
|---|---|
| [المعمارية](ARCHITECTURE.md) | حدود الثقة ودورة حياة الملف وواجهات API الداخلية والتخزين والتعافي. |
| [الأمان](SECURITY.md) | الضوابط الأمنية ونموذج التهديد والاستجابة للحوادث والقيود التشغيلية. |
| [إدارة المفاتيح](KEY_MANAGEMENT.md) | Envelope Encryption وVault Transit ودورة المفاتيح والتدوير وحدود التطوير. |
| [النشر](DEPLOYMENT.md) | الشهادات وtopology الشبكة وsystemd وقواعد firewall وقائمة الإصدار. |
| [تقرير التدقيق الأمني النهائي](FINAL_SECURITY_AUDIT.md) | النتائج الأمنية وقرار الجاهزية والتحقق المطلوب قبل الإنتاج. |

## سجلات التنفيذ

توثق ملفات `PHASE_*.md` قرارات البناء والمراجعة والتعافي وmTLS وعزل البيانات الصريحة والاختبارات الأمنية خلال التنفيذ. احتفظ بها للرجوع التقني، واقرأها مع تقرير التدقيق النهائي قبل تعديل أي جزء حساس للأمان.
